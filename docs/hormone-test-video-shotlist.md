## 0. オープニング
- **画角**: AYA先生の顔出しトーク（バストショット）
- **テロップ**: なし、または院名ロゴのみ

## 1. この検査が測っているもの
- **画角**: 顔出しトーク
- **グラフィック**: P4・E2・コルチゾール・DHEA-Sの4項目を並べたシンプルなアイコン/テキストカード（LP `HormoneTestEvidence` の見出し直後の構成と合わせる）

## 2. 女性ホルモンバランス — P4・E2・P4/E2比
- **画角**: 顔出し＋カットイン
- **グラフィック**: P4とE2のシーソー/天秤のようなシンプルな図解（比率のイメージ）
- **LP連動**: このまま`BodyCgJourney`の「女性ホルモン」CGアニメーション（`FemaleHormoneCg.tsx`：卵巣→プロゲステロン→女性ホルモンの線画）を動画内でも流用・参照可能

## 3. 検査結果から分かること
- **画角**: 顔出しトーク中心
- **カットイン候補**（各項目1カットずつ、3〜4秒）:
  - 排卵・ホルモンのリズム → カレンダー/周期を示すシンプルなモーショングラフィック
  - PMS・月経前の不調 → 上記と共通のグラフィックでも可
  - 更年期関連症状 → 既存の`SymptomSignals`カードデザインを流用（同じ配色・カード形状）
  - 性欲・パートナーシップ → 抽象的なイメージカット（顔出し継続でも可）
  - 体組成・代謝 → `BodyCgJourney`の「血糖・代謝」CG（`LiverCg.tsx`）を流用可能

## 4. コルチゾール・DHEA-Sの読み方
- **画角**: 顔出し＋グラフ解説
- **グラフィック**: `CortisolChart.tsx`のコルチゾールリズム図（起床時〜夜の折れ線）をそのまま画面キャプチャ、またはモーショングラフィック化して使用
- **カットイン**: `BodyCgJourney`の「脳」CG（`BrainCg.tsx`）— 朝のコルチゾール低下と集中力の関係を視覚化

## 5. レポートの見方
- **画角**: 実際のレポート画面（`SampleTestResult`コンポーネントのデザイン、またはそのまま実機画面録画）
- **グラフィック**: 基準範囲バー＋マーカーの動き（「ここを見てください」という指差し/ハイライト演出があると理解しやすい）

## 6. 個別相談への自然な接続
- **画角**: 顔出しトーク
- **テロップ**: `PostApplicationFlow`の4ステップをそのままテロップ化
  1. 検査キットが届きます
  2. 約3週間後、専門医による検査結果の個別解説動画をお届けします
  3. 必要に応じて、グループまたは個別セッションをご案内します
  4. Hormone Journeyがはじまります
- **エンドカード**: 「唾液女性ホルモン検査は、ゴールではありません。あなたのHormone Journeyの入り口です。」（`SalivaTestCta`の結びの一文と統一）

## デザイン統一のポイント

LPのビジュアル言語をそのまま動画に持ち込むことで、「LPを見た後に動画を見ても、動画を見た後にLPに戻っても」違和感がない一体感を作れます。

| 要素 | LP側の実装 | 動画での使い方 |
|---|---|---|
| 配色 | `#C6A96B`（ゴールド）/`#2C2A28`（インク）/`#F5EFE6`（ベージュ背景） | テロップ・グラフィックの配色をこれに統一 |
| コルチゾールグラフ | `CortisolChart.tsx` | 画面キャプチャ or 同デザインのモーショングラフィック |
| 検査結果レポート | `SampleTestResult.tsx` | 画面キャプチャ or 同デザインのモーショングラフィック |
| 症状カード | `SymptomSignals.tsx` | テロップカードのデザインを流用 |
| 体内CGアニメーション | `BodyCgJourney.tsx`配下の4コンポーネント（脳・肝臓・炎症・女性ホルモン） | そのままB-roll、または実写/本格CGへの差し替え時のデザイン参照元に |
